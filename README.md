# XO أونلاين — نسخة الشبكات المختلفة

هذه نسخة مبنية على تصميم ملفك المرفوع (واجهة بسيطة وألوان فاتحة)، مع غرف أونلاين حقيقية باستخدام Node.js وSocket.IO، بدون Firebase.

## التشغيل
1. تحتاج Node.js إصدار 18 أو أحدث.
2. داخل مجلد المشروع نفّذ:
   `npm install`
   `npm start`
3. افتح `http://localhost:3000`.

## النشر ليعمل بين شبكات مختلفة
ارفع المشروع كاملًا إلى استضافة تدعم Node.js وWebSocket (مثل Render أو Railway أو VPS)، واجعل أمر التشغيل `npm start`. بعد النشر شارك رابط الموقع. GitHub Pages وحده لا يشغّل `server.js` ولا يدعم هذا السيرفر.

## ملاحظات
- الغرف والنتائج محفوظة مؤقتًا في ذاكرة السيرفر وتُمسح عند إعادة تشغيله.
- لوحة الترتيب مؤقتة وليست مرتبطة بحسابات دائمة.
- زر «العب على نفس الجهاز» من التصميم الأصلي لم يعد هنا؛ هذه النسخة تركز على الغرف الأونلاين العامة والخاصة.
